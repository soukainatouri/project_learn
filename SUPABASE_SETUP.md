# Supabase Setup Guide

This guide helps you set up a Supabase project and link it to your application.

## 1. Create a Supabase Project

1. Go to [supabase.com](https://supabase.com) and log in or sign up.
2. Click on **New Project**.
3. Select your Organization, enter a **Project Name** (e.g., `Moroccan Math Lesson Planner`), set a secure **Database Password**, and choose a hosting region close to you.
4. Click **Create new project** and wait a couple of minutes for the database to provision.

---

## 2. Retrieve API Credentials

Once your project is ready:
1. In the left-hand sidebar, click on **Project Settings** (the gear icon ⚙️).
2. Click on **API** in the settings menu.
3. Locate the following two values under **Project API keys**:
   - **Project URL**: Under the *Config* section, copy the `URL` (e.g., `https://xxxxxx.supabase.co`).
   - **Anon Key**: Under *Project API keys*, copy the `anon` / `public` key.

---

## 3. Configure Environment Variables

Open the [.env.local](file:///C:/Users/grandy/projects/project_learn/.env.local) file in your project directory and replace the placeholders with your actual keys:

```env
VITE_SUPABASE_URL=https://your-actual-project-url.supabase.co
VITE_SUPABASE_ANON_KEY=your-actual-anon-public-key
```

Save the file and restart your development server.

---

## 4. (Optional) Disable Email Confirmation for Testing

By default, Supabase requires users to confirm their email before logging in. To disable this for local testing/development:
1. In the left-hand sidebar, navigate to **Authentication** (the user icon 👤) > **Providers**.
2. Click on **Email** to expand the provider settings.
3. Toggle **Confirm email** to **OFF**.
4. Click **Save**.

Now you can sign up with any test email (even dummy ones like `test@example.com`) and log in immediately.

---

## 5. Database Table Setup

To store math lesson plan forms submitted by users, you must create a `form_submissions` table.

1. In the left-hand sidebar, click on the **SQL Editor** icon (looks like `>_`).
2. Click **New Query**.
3. Copy and paste the following SQL script into the editor:

```sql
-- Create the form_submissions table
create table public.form_submissions (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users not null,
  payload jsonb not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable Row Level Security (RLS) to secure the data
alter table public.form_submissions enable row level security;

-- Policy to allow authenticated users to save their own submissions
create policy "Allow users to insert their own submissions"
  on public.form_submissions
  for insert
  with check (auth.uid() = user_id);

-- Policy to allow authenticated users to view their own submissions
create policy "Allow users to view their own submissions"
  on public.form_submissions
  for select
  using (auth.uid() = user_id);
```

4. Click the **Run** button at the bottom right.

You are all set! Your application will now register users, let them log in, and securely save their generated Moroccan Math lesson plan data.
